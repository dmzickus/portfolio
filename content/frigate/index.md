A roommate and I wanted to try Frigate's local object detection. It would run on a VM, feed events into Home Assistant, and store no video. The first camera was going to be the old living room wall tablet, and then the 3D printers. The tablet camera has since been retired, so this is on hold. If outdoor cameras ever go up, this is the first thing I'll set up.
